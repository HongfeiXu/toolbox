# 工具箱 🛠️

一个本地工具集合网页，提供常用的转换和计算功能。所有操作在客户端完成，无需服务器支持。

## ✨ 功能特性

### 🎨 第一批 - 核心功能

#### 1. **色值转换**
- 支持 HEX、RGB、HSL 三种格式互相转换
- 可视化取色盘：按住并拖动选择颜色
- 实时颜色预览
- 一键复制各种格式

#### 2. **时间戳转换**
- 秒级时间戳 ↔ 毫秒级时间戳转换
- 时间戳 ↔ 日期时间互转
- "获取当前时间戳"快捷按钮
- 支持失焦和按 Enter 确认

#### 3. **单位转换**
- **存储单位**：B, KB, MB, GB, TB
- **长度单位**：m, km, cm, mm
- **重量单位**：g, kg, mg, t
- 实时转换结果

### 💻 第二批 - 开发者工具

#### 4. **JSON 格式化**
- 美化：格式化成易读的形式
- 压缩：移除所有空白字符
- 验证：检查 JSON 格式是否正确
- 实时反馈状态

#### 5. **Base64 编码/解码**
- 文本 ↔ Base64 互转
- 完整的 UTF-8 支持
- 格式验证

### 🔧 第三批 - 实用工具

#### 6. **UUID 生成器**
- 生成 UUID v4
- 支持批量生成（1-100 个）
- 一键复制所有结果

#### 7. **字数统计**
- 实时统计字符数
- 字数统计（不含空格）
- 单词数统计
- 行数统计

#### 8. **URL 编码/解码**
- URL 编码/解码
- 处理特殊字符
- 实时反馈

## 📖 使用说明

### 色值转换

1. **输入框输入** - 在任意色值框输入值
   - HEX: `#FF5733`
   - RGB: `rgb(255, 87, 51)`
   - HSL: `hsl(10, 100%, 60%)`

2. **取色盘选择** - 按住并拖动选择颜色
   - 横轴：调整饱和度（从灰到纯色）
   - 纵轴：调整亮度（从亮到暗）
   - 下方色相条：调整颜色本身

3. **实时预览** - 颜色预览框实时显示

4. **复制结果** - 点击对应的"复制"按钮

### 时间戳转换

1. 在任意字段输入值
2. 失焦或按 Enter 确认
3. 其他字段自动填充
4. 点击"获取当前时间戳"快速获取现在的时间

### 单位转换

1. 输入数值
2. 选择源单位和目标单位
3. 结果自动计算显示
4. 复制按钮快速复制结果

### JSON 格式化

1. 在左侧输入框粘贴 JSON
2. 选择操作：
   - **美化**：格式化成易读的形式
   - **压缩**：移除所有空白
   - **验证**：检查格式是否正确
3. 结果显示在右侧

### Base64 编码/解码

1. 在输入框输入文本或 Base64 编码
2. 点击 **编码** 或 **解码**
3. 结果显示在输出框

### UUID 生成

1. 输入生成数量（1-100）
2. 点击 **生成**
3. 结果显示在下方
4. 点击 **复制所有** 复制所有结果

### 字数统计

1. 在输入框粘贴或输入文本
2. 自动实时统计：
   - 字符数（含空格）
   - 字数（不含空格）
   - 单词数
   - 行数

### URL 编码/解码

1. 在输入框输入 URL 或文本
2. 点击 **编码** 或 **解码**
3. 结果显示在输出框

## 📝 常见问题

**Q: 我的数据会被上传吗？**
A: 不会。所有操作都在浏览器本地完成，没有服务器交互。

**Q: 支持离线使用吗？**
A: 是的，将 HTML 文件保存到本地后，可以离线使用。

**Q: 可以复制转换结果吗？**
A: 可以，每个工具都有"复制"按钮，支持一键复制到剪贴板。

**Q: 色值转换中，如何使用取色盘？**
A: 在取色盘上按住鼠标并拖动即可实时选择颜色，松开鼠标时颜色确认。

**Q: JSON 格式有问题时会提示吗？**
A: 是的，输入不合法的 JSON 时会显示红色边框和具体错误信息。

## 🎯 快速技巧

- **按 Tab 键** 在输入框间快速切换
- **输入后按 Enter** 确认转换（色值、时间戳等）
- **复制按钮有反馈** 点击后会显示"已复制!"提示
- **错误输入** 会显示红色边框和具体错误信息
- **取色盘实时更新** 输入色值时，取色盘光标会自动移到对应位置
